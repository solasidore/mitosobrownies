# mitoso brownie

Landing/homepage responsive basada en el mockup aprobado.

## Archivos
- `index.html`: estructura semántica y contenido.
- `styles.css`: diseño responsive y fidelidad visual.
- `script.js`: carrito interactivo.
- `assets/`: fotografías recortadas del mockup para mantener la dirección visual.

## Uso
Abre `index.html` en el navegador. Para desarrollo local también puedes servir la carpeta con cualquier servidor estático.
